# Elektronic Android (Электроник)

Локальная русская голосовая диктовка и управление через голосовые команды на Android, используя Magisk.

Этот модуль позволяет:
- Распознавать речь в текст с помощью модели GigaAM v3 (ONNX) полностью оффлайн.
- Управлять устройством голосом через нажатие кнопки громкости вниз.

**Базируется на проекте:** [giga-pisar](https://github.com/moznoazachem/giga-pisar)

---

## Возможности

### Голосовая диктовка
- Распознавание речи в текст через локальную модель GigaAM v3.
- Автоматическая вставка текста в активное поле или копирование в буфер обмена.
- Поддержка двух режимов работы: локальный сервер и CLI.

### Голосовые команды
- Управление устройством через голосовые команды с префиксом `андроид` (например, "андроид, перезагрузи телефон").
- Поддержка команд для:
  - Перезагрузки и выключения устройства
  - Настройки громкости и фонарика
  - Скриншотов и блокировки экрана
  - Управления медиаплеером
  - Запуска приложений (Телеграм, WhatsApp, Калькулятор и др.)
  - Проверки статуса root, температуры процессора, состояния батареи и других системных параметров

### Добавление своих команд

Чтобы добавить свои голосовые команды, отредактируйте файл **commands.conf**.

Формат команд:

```
фраза_или_регулярка = shell_команда
```

Примеры:

```
перезагрузи телефон = reboot
включи фонарик = cmd flashlight on
открой телеграм = monkey -p org.telegram.messenger 1
```

1. Откройте файл **commands.conf** в текстовом редакторе.
2. Добавьте новые команды в формате `фраза = команда`.
3. Сохраните файл.
4. Перезагрузите устройство или перезапустите демон модуля.

**Примечание:** Префикс команд (например, "андроид") можно изменить в файле **giga.conf** (`COMMAND_PREFIX`).

## Установка

1. Убедитесь, что на устройстве установлен Magisk.
2. Скачайте ZIP-файл модуля.
3. Установите модуль через Magisk Manager: **Module → Install from storage**.
4. Перезагрузите устройство.

---

## Настройка

Основные параметры конфигурации находятся в файле **giga.conf**. Можно изменить:
- Кнопку активации (по умолчанию — громкость вниз).
- Время удержания клавиши для активации.
- Метод записи звука (auto, app_process, tinycap).
- Режим распознавания (local_server, local_cli, remote).
- Включение/отключение виброотклика и автоматической вставки текста.

---

## Структура модуля

- **bin/** — Скрипты для работы модуля и обработки звука.
- **server/** — Python-сервер для распознавания речи.
- **model/** — Модель GigaAM v3 (ONNX-файлы).
- **commands.conf** — Список поддерживаемых голосовых команд.
- **service.sh** — Запускается при загрузке устройства для инициализации модуля.

---

## Использование

1. Удерживайте кнопку громкости вниз, чтобы активировать запись.
2. Говорите текст или команду, например: "андроид, открой Телеграм".
3. После отпускания кнопки текст или команда будет выполнена.

---

## Поддержка и отладочная информация

- Логи работы модуля доступны по пути: `/data/local/tmp/giga_pisar.log`.
- Для отладки можно временно включить логгирование в файле **giga.conf** (`DEBUG_LOG=1`).
